Detailed Description

Bazinė abstrakti klasė, aprašanti žmogų su vardu ir pavarde.

Ši klasė naudojama kaip pagrindas studentams ar kitiems asmenims. Turi grynai virtualią funkciją info(), todėl negali būti sukurta tiesiogiai.
